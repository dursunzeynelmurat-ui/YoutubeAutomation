# Gameplay backgrounds (for brainrot shorts)

Drop looping gameplay videos here (e.g. 30-min clips). `brainrot.py` picks one,
loops/trims it to the voice length, center-crops to 9:16, and overlays captions.

## ⚠️ Licensing (this is a monetized channel)
Gameplay footage is usually **copyrighted** (Subway Surfers, GTA, Minecraft, etc.)
and can trigger YouTube Content ID / demonetization. Prefer:
- **royalty-free / Creative Commons** gameplay explicitly cleared for reuse,
- **self-recorded** gameplay you own, or
- stock loops you've licensed.

Supported: .mp4 / .mov / .mkv / .webm. Any resolution (it gets cropped to 1080x1920).
